
# Research Software ETL  
*Extraction, transformation, and integration of research software metadata for FAIR assessment*

## Overview 

This repository contains the ETL pipeline that automates the process of extracting, normalizing, enriching, and integrating metadata about life-science software from multiple sources. It prepares the resulting data for evaluation through the FAIRsoft indicators, a framework that measures transparency, reproducibility, and sustainability of research software.

The ETL forms the backbone of the Research Software Observatory, a platform designed to monitor and assess software quality across the life-science ecosystem.
